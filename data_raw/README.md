# data_raw

Copies immuables des réponses API et fichiers téléchargés. Chaque collecte est
placée dans un sous-dossier horodaté UTC. Le script de collecte ne remplace
jamais un fichier brut existant. Les fichiers volumineux ne sont pas suivis par
Git; le journal de collecte, les URL, les sommes SHA-256 et les licences assurent
la traçabilité.
